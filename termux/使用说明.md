# 手机版（Termux）使用说明

不需要打包 APK，直接在手机上运行 Python 命令行版，功能与电脑完全一致
（链接批量下载 / 收藏批量下载 / 动图合成 GIF / 下载历史去重）。

## 安装步骤（约 5~10 分钟）

1. **安装 Termux**：从 [F-Droid](https://f-droid.org/packages/com.termux/) 下载
   （不要用 Google Play 里的旧版），安装后打开。

2. **把手机包传到手机**：把 `pixiv-phone` 文件夹（或 zip）通过微信/QQ/USB
   传到手机的 `Download`（下载）目录，zip 的话先解压。
   文件夹里应有三样东西：`pixiv_dl.py`、`setup.sh`、本说明。

3. 在 Termux 里依次执行（每行回车）：

   ```bash
   termux-setup-storage          # 弹出权限请求, 点允许
   cd ~/storage/downloads/pixiv-phone
   bash setup.sh                 # 自动安装 python / Pillow / requests
   ```

4. 装完先测试一下：

   ```bash
   python pixiv_dl.py history count
   ```

   显示"下载历史共 0 条"即正常。`config.json` 和 `download_history.db`
   会生成在当前目录（就是 pixiv-phone 文件夹里）。

## 使用

```bash
cd ~/storage/downloads/pixiv-phone

python pixiv_dl.py bookmarks                 # 下载全部收藏
python pixiv_dl.py bookmarks --private       # 私密收藏
python pixiv_dl.py links https://www.pixiv.net/artworks/123456
python pixiv_dl.py history count             # 看已下载多少
```

- 第一次使用会要求粘贴 PHPSESSID（手机浏览器登录 pixiv → 也按 F12 不方便的话，
  建议在电脑浏览器里复制 cookie 值，再粘贴到手机）。也可以直接编辑
  `config.json` 填进去。
- 下载的文件保存在 `pixiv-phone/downloads/` 里，用手机文件管理器就能看到。

## 手机必须设置代理

手机网络直连是访问不了 pixiv 的，需要让流量走代理。两种方式任选：

**方式一（推荐）：`--proxy` 参数**。前提是手机上装有代理软件（如 v2rayNG、
Clash Meta for Android 等），并在其设置里开启"允许局域网/本地共享"或记住
其本地 HTTP 端口（v2rayNG 默认 10809 或 1080，Clash 默认 7890）：

```bash
python pixiv_dl.py bookmarks --proxy http://127.0.0.1:7890
```

成功一次后会写进 `config.json`，之后不用再带这个参数。

**方式二：环境变量**（对当次会话生效）：

```bash
export HTTPS_PROXY=http://127.0.0.1:7890
python pixiv_dl.py bookmarks
```

## 常见问题

- **锁屏后下载中断**：Termux 在后台可能被系统冻结。拉一个 Termux 的
  通知栏常驻通知（下拉通知栏点 "Acquire wakelock"，或装 Termux:Boot），
  并且下载时保持亮屏最稳妥。中断了也没关系——重跑会自动跳过已下载的。
- **报 403 / 连接超时**：基本都是代理没通，检查代理软件端口。
- **报 429**：被 pixiv 限流了，等几分钟再跑（`--delay 2` 放慢速度）。
